# Como contribuir

1. Escolha ou crie uma *issue* (use os modelos) e peça para ser atribuído a ela.
2. Crie uma ramificação: `feat/nome-curto`, `fix/nome-curto` ou `docs/nome-curto`.
3. Faça *commits* pequenos com mensagens `feat:`, `fix:`, `docs:`, `test:`, `refactor:` ou `chore:`.
4. Rode os testes (`make test`) e o formatador (`make lint`).
5. Abra um *pull request* e peça revisão. Ninguém aprova o próprio PR.
6. Nunca versione senhas, chaves, *tokens* ou dados pessoais.

**Definição de pronto**: funciona, foi testado (simulação ou real), está documentado e foi revisado por outra pessoa.
